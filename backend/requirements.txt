# Accepted, monitored risk: this app only ever signs/verifies JWTs with
# HS256 (a symmetric algorithm), so the vulnerable RSA/ECDSA/ASN.1 code
# paths in both packages are never actually reached by anything this app
# does. Re-check this note if the app ever adds an asymmetric JWT algorithm,
# or if python-jose ships a release that relaxes the pyasn1 pin.
